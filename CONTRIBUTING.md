### PRs

Please keep PRs small and targeted. My brain does not work super well. 

If your PR changes a large amount of things they need to be individual commits, and don't push like 20 commits either. 

I have a responsibility to maintain deep familiarity with the codebase and massive modifications eat up a lot of time.

If you are wanting to start in on some large massive SLOC change please reach out. 

--- 

### AI Usage

Generally I am fine with LLM assisted work being pushed; there is a lot of boilerplate
work required with Binary Ninja workflow stuff, and LLMs were used in several areas of this project.

however:
* Changes must be small and targeted. Do not give me a "improved several things" PR.
* Usage must be disclosed (pleaseeee)
* Documentation must be handwritten
* Comments in code must be handwritten.

<b>do not AI generate comments or your PR description. actually read the code and detail the changes</b>
